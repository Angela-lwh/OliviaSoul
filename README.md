# OliviaSoul · 林离离线续作

> 官方服务器关停之后，让《林离》重新亮起来的开源工程。
> 本仓库是 [yilangren/OliviaSoul](https://github.com/yilangren/OliviaSoul) 的社区续作（fork），在原版基础上补齐了**云分享**与一整套运维能力。

![OliviaSoul](assets/oliviasoul-cover.png)

---

## 一、她是一艘航母

官方关服之后，《林离》只剩下一副空壳：界面还在，但写信、曲库、歌单这些需要服务器的功能全部停摆。
这个项目做的事情，本质上是**为这具空壳配一艘自己的航母**——把原来必须依赖官方后端才能起飞的一切，搬到自己手里重新跑起来。

可以这样理解这套系统的分工：

| 航母部件 | 对应模块 | 作用 |
|---|---|---|
| **舰体** | 本地服务 `app/server.js` | 接管游戏原本依赖的官方接口，让客户端以为「服务器还在」 |
| **弹射器** | `patch-feapp-local.ps1` + 游戏内注入层 | 把游戏前端改造成能被我们自己接管的形态，并注入新的入口 |
| **舰载机** | 写信 / 回信 / 曲库 / 云分享 / 记忆 / 转写 | 真正被你使用的功能，全部从甲板上起飞 |
| **塔台** | 桌面控制端 + 管理看板 | 挂载服务、导入记忆、查看分享与配额 |
| **补给舰** | 阿里云 OSS（可选） | 把整首曲目存在云端，随时补给给另一台机器 |
| **编队** | 客户端 + 云分享服务 + 对象存储 | 三件套协同，任何一环都能自建 |

所以它不是一个「补丁」，而是一个**平台**：游戏本体是它搭载的机型，功能模块是它的舰载机，云分享服务是它停靠的补给港。
你可以只用舰体（纯离线写信），也可以把整支编队都拉起来（自己部署云分享服务器）。

## 二、它能做什么

### 已经恢复的官方功能

- **写信与回信**：接入任意 DeepSeek 兼容接口，林离按人设与长期记忆回信
- **记忆系统**：十三字段跨封情感账本、五段式长期记忆、`.soul` 单文件备份与恢复
- **曲库与歌单**：离线曲库、封面兜底、音乐桌面播放
- **本地转写**：随包内置 Whisper small 模型与 FFmpeg，可把音频/视频转成文字
- **独立 Harness**：脱离主工程单独跑回信流水线

### 本续作新增：云分享（航母的补给线）

把本机整首曲目（6 个视角视频）打成 8 位分享码，对方输入即可还原到自己电脑：

- **上传**：游戏内「演奏」页点「上传演奏」，选一首本机曲目，生成分享码
- **获取**：点「获取」输入对方的分享码，直接还原到本机曲库并自动刷新列表
- **我的上传**：列表里可复制分享码（会提示剩余有效期）、可一键删除分享
- **内容去重**：同一首歌在 OSS 上**只存一份**，别人再传直接秒传、不占新空间
- **7 天有效期**：超过 7 天无人下载的分享会自动删除，省存储费
- **完整性校验**：上传前比对内容哈希，下载后逐文件校验 SHA256
- **配额**：每个昵称/设备每天 3 首上传，下载不限次数
- **管理看板**：OSS 占用、上传/下载统计、配额、剩余有效期

## 三、使用教程

### 1. 下载安装

下载 `OliviaSoul-2008.2.7-Setup.exe` 安装（需要管理员权限）。

> ⚠️ **不要安装到《林离》游戏文件夹内**，否则会闪退。
> 不想安装的可以用 `OliviaSoul-2008.2.7-Portable.zip`，解压后直接运行 `OliviaSoul.exe`。

### 2. 第一步：填 DeepSeek API Key

打开 OliviaSoul →「基础设置」→ 填入自己的 DeepSeek API Key 并保存。
需要时可以自定义模型名和兼容接口地址，再点「连通性测试」确认。

> 程序和仓库都不含预设 Key，也不会上传或公开你填的密钥。

### 3. 第二步：导入记忆

官方远端服务器已关停，需要手动导入：

- 导入此前备份的 `.soul` 文件；或
- 粘贴历史往来全文，让 AI 识别为逐封记忆
- 也可以在「记忆管理」里逐封新建/修改

### 4. 第三步：挂载服务

「基础设置」→ 选择游戏启动程序 → 确认端口（默认 27149）→ 点「一键挂载服务」。
界面显示已挂载后，保持 OliviaSoul 在后台运行即可。

挂载会做三件事：给 `feapp.dat` / `webplayer.dat` 打补丁、注入游戏内新入口、把客户端接口指向本地服务。

### 5. 第四步：写信

打开游戏信箱，像平时一样写信并发送。信的那边，上海的琴凳上，《夜曲》中，林离一直在。

### 6. 云分享怎么用

**上传（把歌分享给别人）**

1. 进游戏「演奏」页，找到卡片上的「上传演奏」
2. 选一首本机曲目 → 等进度走完 → 得到 8 位分享码
3. 在「我的上传」里点「复制」，提示里会带剩余有效期

**获取（拿到别人的歌）**

1. 「演奏」页点「获取」
2. 输入对方的 8 位分享码，输入满 8 位会自动显示曲名/大小/预计耗时
3. 点「获取」→ 自动下载、校验、还原到本机曲库，并刷新曲库列表
4. 本机已有同样内容时会直接提示「无需重复获取」

**删除**

- 曲库列表行悬停 → 右侧「删除」：删掉本机文件（移到 `%APPDATA%\OliviaSoul\deleted-songs`，可手动恢复）与曲库记录
- 「我的上传」→「删除」：删掉本机记录**并同时删除服务器上的分享**（没有别的分享引用时 OSS 文件也会被释放）

### 7. 常见问题

| 现象 | 处理 |
|---|---|
| 首次回信很慢 | 正常，导入记忆后的第一封可能需要一小时；后续一般十分钟内 |
| 曲库封面空白 | 检查 OliviaSoul 是否在后台运行（封面由本地服务 `/cover` 提供） |
| 获取时提示「分享码不存在」 | 对方已删除，或分享超过 7 天无人下载被自动清理 |
| 上传提示「已达上限」 | 每个昵称/设备每天 3 首，次日自动恢复 |
| 想换端口 | 「基础设置」里改端口后重新挂载即可 |

## 四、自建云分享服务（可选）

不部署也能用（分享服务地址留空即禁用云分享）。想自己搭一条补给线：

```bash
# 服务器：Node 20+，零 npm 依赖
/opt/olivia-share/{server.mjs, oss.js, admin.html, public/}
/etc/olivia-share.env   # 端口、APP_SECRET、管理员账号、阿里云 OSS AK/SK
systemctl enable --now olivia-share
```

客户端在「基础设置」里填 `http://<你的服务器>:8787` 和应用密钥即可。

要点：

- 存储走**阿里云 OSS**，服务器只负责签名与记账，不转发流量（省带宽）
- 内容按 SHA256 去重，同一首歌只存一份
- 建议给 OSS 加生命周期规则：未完成分片 1 天后自动清理（服务端启动时会自动配置）
- 管理看板：`http://<服务器>/admin`

## 五、从源码构建

```powershell
Set-Location .\source\local-service
npm install
npm test
npm run build:win          # 完整构建（需要 .NET SDK + Inno Setup 6）
```

如果本机没有 .NET SDK，也可以复用已安装版本的原生宿主重新打包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\source\local-service\packaging\build-repack.ps1 `
  -InstalledRoot "C:\Program Files\OliviaSoul"
```
